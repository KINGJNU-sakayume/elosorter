# 후속 실험: 5단계 응답 모형과 비교 쌍 선택 (2026-11)

> **오프라인 연구 전용**. 앱의 레이팅 엔진, 저장 포맷, UI, 기존 비교 기록을 변경하지 않습니다.

## 연구 근거와 질문

- 다섯 단계 응답을 0/0.25/0.5/0.75/1이라는 분수 승리로 해석하는 Bradley–Terry(BT)와, 다섯 범주의 발생 확률을 직접 기술하는 **순서형 누적 로짓** 중 무엇이 비교 수 대비 실제 선호 순서를 잘 복원하는가?
- 상위권 집중은 Top 10을 빨리 개선하지만, 초기에 티어 3으로 잘못 분류된 실제 최상위 곡을 놓치지는 않는가?
- 상위권 비교 80% + 전체 탐색 20%가 그 위험을 낮추는지, 그 대가로 상위권 정확도를 얼마나 희생하는가?

관련 문헌:
- [Davidson (1970), 무승부를 허용하는 BT 확장](https://doi.org/10.1080/01621459.1970.10481082). 본 PR의 순서형 모형은 Davidson 모델이 아니라 다섯 범주를 직접 모델링하는 **cumulative logit** 대안이다.
- [Penn State STAT 504, 누적 로짓을 이용한 순서형 결과](https://online.stat.psu.edu/stat504/Lesson08).
- [Mohajer et al. (2017), 능동 Top-K 순위 학습](https://proceedings.mlr.press/v70/mohajer17a.html).
- [Ren et al. (2020), Top-K 발견의 비교 표본 복잡도](https://proceedings.mlr.press/v119/ren20a.html).

## 실험의 비교 단위

**모델 A/B**: 분류된 곡, 다음 비교 쌍, 5단계 응답이 모두 동일하다. 그 비교 기록으로 기존 BT와 새 순서형 모형을 각각 적합해 결과를 비교한다. 순서형 모형의 임계값은 단일 가상 사용자 응답 방식(중앙 ±0.35, 극단 ±1.5)에 고정한다.

**비교 전략 A/B/C**: 같은 기존 BT 적합식을 사용하고, 다음 쌍 선택만 바꾼다.
1. 전체 탐색: 기존 `focus=all`
2. 상위권 집중: 기존 `focus=top`
3. 혼합: 80% 상위권 + 20% 전체 탐색

**동일한 비교 결과**: 곡 ID 쌍과 해당 쌍이 등장한 횟수를 해시해서 난수를 만들기 때문에, 서로 다른 전략이라도 같은 쌍의 같은 번째 비교 결과를 동일하게 만든다. 쌍 선택 자체가 다르므로 두 전략의 관측 데이터는 다를 수 있다.

**평가 지표**: 실제 잠재 점수 대비 모든 쌍의 순서 정확도, Top 10 집합 재현율, Top 30 집합 재현율. 시드별 평균과 표준오차(±SE; 신뢰구간이 아님)를 표시한다.

## 취약성 시나리오

| 시나리오 | 사용자 반응 | 티어 잡음 |
|---|---|---|
| 기본 | 중앙 ±0.35, 강한 선호 ±1.5 | 0.5 |
| 티어 오분류 | 실제 최상위 곡 1개를 Tier 3으로, 최하위 1개를 Tier 1로 교환 | 1.1 |
| 응답 문턱 불일치 | 중앙 ±0.2, 강한 선호 ±2.2 (순서형 모형의 고정 임계값과 다름) | 0.5 |

## 실행

- `npm run bench` — 작게 줄인 결정적 회귀 실험과 기존 시뮬레이션.
- `npm run bench:full` — 각 시나리오 120곡 × 12개 시드 × 곡당 4회 비교.
- 결과가 콘솔에 Markdown 표 형태로 출력된다.
- 예측 데이터는 **가상 사용자**가 생성하므로 실제 Spotify 사용자의 정확도를 주장하는 근거가 될 수 없다.

## 해석 제한

1. 가상 사용자 선호가 단일 잠재 점수와 로지스틱 잡음을 따른다는 전제 아래 결과가 나온다. 장르별/시점별로 선호가 달라지는 실제 음악 취향은 더 복잡하다.
2. 기본 시나리오의 응답 임계값은 순서형 모델이 사용하는 임계값과 같아 순서형에 유리하다. 별도의 임계값 불일치 시나리오를 반드시 함께 해석해야 한다.
3. Top 10/30은 **정확한 순서**가 아니라 **해당 집합에 포함되었는지**를 평가한다. 상위권 내부 순서 정밀도는 별도 측정이 필요하다.
4. 실험자는 임계값을 사용자 데이터에서 학습하지 않았고, 곡 간 점수의 비이행적 순환 선호도 모델링하지 않았다.
5. 테스트의 통과는 모델의 우월성을 뜻하지 않는다. 평균 정확도, 시드별 편차, 시나리오 간 안정성을 종합 검토한 뒤 제품 도입 여부를 결정해야 한다.
6. 현행 점수와 세션을 새로운 우도식으로 재해석하면 기존 순위가 달라질 수 있다. 이 PR은 운영 전환을 포함하지 않는다.
