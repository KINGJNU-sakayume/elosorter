# 순위 알고리즘 검토 및 보수적 개선 (2026-11)

> 범위: 개인 Spotify 곡 3티어 사전분류 + 5단계 쌍대 비교 + 베이지안 Bradley–Terry MAP.
> 목적: 기존 v2 세션·UI·비교 데이터 형식을 깨지 않고 검증 가능한 오류부터 수정한다.

## 1. 선행 연구와 선택

1. **Bradley–Terry 모델**: 단일 잠재 점수 차를 로지스틱 승률로 연결한다. 단일 차원으로 요약하기 어려운 다면적 취향, 비교의 의존성은 모델 가정 밖이다. [Wu et al., JRSS A, 2022](https://doi.org/10.1111/rssa.12959).
2. **동률·선호 강도**: Davidson(1970)은 무승부를 별도의 확률로 다룬다. Bradley–Terry의 반승(0.5) 처리는 실용적 근사지만 동률의 발생 메커니즘을 구별하지 않는다. 현행 0/0.25/0.5/0.75/1은 분수 승리 점수이며, 5개의 결과를 갖는 *순서형 관측 모형*이 아니다. [Davidson, JASA 1970](https://doi.org/10.1080/01621459.1970.10481082); [bpcs, Behavior Research Methods](https://doi.org/10.3758/s13428-021-01714-2).
3. **능동 Top-K**: 목적이 전체 순위 정확도인지, 상위 K개 발견인지에 따라 비교 쌍 할당의 효율이 달라진다. 기존 '상위권 집중'의 상위 15% 풀은 효율적이지만 초기 분류에서 빠진 다크호스를 찾는 데 제약이 있다. [Mohajer et al., ICML 2017](https://proceedings.mlr.press/v70/mohajer17a.html); [Ren et al., ICML 2020](https://proceedings.mlr.press/v119/ren20a.html).
4. **불확실성**: 현재 `1 / H_ii`는 전체 헤시안 역행렬 `(H^{-1})_ii`가 아니라 대각 근사다. 따라서 실제 사후 분산 및 두 곡 점수의 공분산을 반영하지 못한다. 표시되는 ± 및 예상 정확도는 **모델 기반 근사**로 이해해야 한다. [Wu et al., 2022](https://doi.org/10.1111/rssa.12959).

## 2. 이 변경에서 구현한 것

### A. 압축·마이그레이션된 과거 비교 증거 보존

기존 `withTier`는 티어 변경 시 `prior`를 무조건 버렸다. 하지만 `prior`에는 오래된 비교를 압축한 정보나 v1에서 복원한 정보가 들어 있다. 특히 저장 기록 4,000건을 넘어 압축이 일어난 세션에서 티어를 바꾸면 이 정보가 소실되었다.

이제 곡별 정규분포로 근사 보존한 사후 정보 `N(m_old, v_oldPost)`에서 옛 티어 사전분포 `N(μ_old, v_oldPrior)`를 빼서 가우시안 **근사 우도**를 복원하고, 새 티어 사전분포 `N(μ_new, v_newPrior)`를 결합한다.

- `q_evidence = max(0, 1/v_oldPost - 1/v_oldPrior)`
- `h_evidence = m_old/v_oldPost - μ_old/v_oldPrior`
- `q_new = q_evidence + 1/v_newPrior`
- `m_new = (h_evidence + μ_new/v_newPrior) / q_new`

티어 비율이 달라지면 다른 곡들의 티어 사전분포도 바뀌므로 **수정하지 않은 곡들의 명시적 사전분포도 함께 재기준화**한다. 기존 세션 스키마와 비교 점수는 바꾸지 않는다.

**한계:** 이전 압축 자체가 비교 그래프의 곡 간 공분산을 버린 근사이므로 이 작업으로 과거 비교가 완전 복원되는 것은 아니다. 압축 기록이 없던 세션에는 영향이 없다.

### B. 아직 보지 않은 쌍을 우선 사용

기존 페어링은 A와 레이팅이 가장 가까운 24곡만 살폈다. 그 24곡과 모두 비교했으면 다른 미비교 곡이 있어도 이전 쌍을 되풀이했다. 이제 24곡이 모두 소진되면 레이팅 순위의 바깥으로 탐색을 확장해 미비교 상대를 먼저 찾는다.

- 초기 24곡 탐색, A 선택 규칙, 왼쪽/오른쪽 무작위화는 그대로다.
- 컴팩션 전에 이미 본 쌍과 건너뛰기 기억 목록만 참조하므로, 이미 압축되어 없어진 오래전 쌍까지 판별할 수는 없다.
- 수동으로 알려진 비교 쌍을 피하는 정상 동작에 회귀 테스트를 추가했다.

## 3. 안전성을 위해 이번 변경에서 하지 않은 것

- 5단계 결과를 순서형 로짓/프로빗으로 바꾸지 않았다. 현행 기록에는 "조금 더"의 사용자별 기준이 없고, 의미를 바꾸면 과거 랭킹을 일괄 재해석할 위험이 있다.
- `σ`를 정확한 베이지안 신뢰구간이라고 주장하거나, 단지 표시상 '정확도'가 높아지는 식의 임의 보정은 하지 않았다.
- 상위권 집중 모드에 임의의 탐색 확률을 추가하지 않았다. 기준 벤치마크 없이 Top-10 성능이 떨어질 가능성이 있기 때문이다.
- 기존 4,000건 임계치의 근사 압축을 삭제하지 않았다. 메모리, 저장 용량, 응답 지연의 상한을 지키기 위한 결정이다.

## 4. 후속 연구 실험 설계

동일한 시드·동일한 가상 사용자와 더 현실적인 오라클을 사용해 다음을 독립 비교한다.

- **응답 모형 A/B:** 분수 승리 BT(현재) vs 순서형 누적 로짓(5범주) vs Davidson 무승부 + 강도 분리. 이미 기록한 세션은 무조건 그대로 유지하며 새 모형은 별도 실험에서만 테스트.
- **능동 쌍 선정 A/B:** 현재 σ 비율 + 근접 쌍 vs 정보량 개선 vs 상위권 90% + 탐색 10% vs 80/20.
- **오라클:** 가우스 + 로지스틱 잡음 외에도 순환 선호, 장르별 다차원 효용, 초기 티어 오분류, 중간에 취향이 바뀌는 세션.
- **측정 지표:** 전체 쌍 순서 정확도, 순위 상관, Top-10/Top-30 적중률·순서, 미비교 곡 커버리지, 비교당 계산 시간, 저장 데이터 크기, 사용자 재비교 일치도, 표시된 60/80/90%의 경험적 보정 정도.
- **실험 원칙:** 단일 시드 또는 소수 시드에 맞춘 가중치 조정을 피하고, 홀드아웃 시드에서 신뢰구간과 실패 사례를 보고한다.

## 5. 검증할 회귀 경로

1. 옛 v1 마이그레이션 사전분포가 있는 곡의 티어를 수정해도 `prior`가 소실되지 않는다.
2. 임의 곡의 티어를 바꿨을 때, 고정된 증거가 강한 미변경 곡의 추정 평균이 티어 비율 변화에 휘둘리지 않는다.
3. 가장 가까운 24곡을 이미 비교했더라도 아직 비교하지 않은 더 먼 곡을 우선 제시한다.
4. 기존 BT 수렴, 되돌리기, 레이팅 재계산, 비교 시뮬레이션은 계속 통과한다.
